# A. Halliwell Studio: initial asset kit

Creative web design and development portfolio. No portrait required.

## Included
- assets/flower-icon.png, assets/jelly-heart.png, assets/sparkle.png: separate transparent graphics generated with the built-in image tool.
- motion-preview.html: open after extracting the ZIP to preview CSS motion.
- motion.css: reusable rotation, heartbeat and twinkle animations with reduced-motion support.
- assets/flower-backdrop.png: original Y2K flower artwork. Test at different background scales before finalizing; seamless edges need visual verification.
- palette.css: initial colors for the site, independent of the image.

## Still needed before the final portfolio build
Capture the actual Maison Rivière, Willow Lily Estate, and Vanta Social websites. Do not use generated mockup thumbnails as screenshots of your work.
For each project: one desktop screenshot (1440px wide), one mobile screenshot (390px wide), optional 10–15 second screen recording demonstrating an interaction. Hide personal information and use demo data.
Suggested filenames: maison-desktop.webp, maison-mobile.webp, willow-desktop.webp, willow-mobile.webp, vanta-desktop.webp, vanta-mobile.webp.

## Uploading
Unzip this kit first. Upload the assets folder into the public folder of a typical Vite/React or Next.js project. Image URL then becomes /assets/flower-backdrop.png. For a plain static site, keep assets beside index.html and use ./assets/flower-backdrop.png. Confirm the actual repository structure before connecting it.

GitHub stores the files. The website preview shows the layout and movement once code is connected. The pattern itself is a static image; parallax movement belongs in code.

## Direction
Full-site flower backdrop, readable cream/blush panels floating above, generous gaps revealing the pattern, no face photograph, clean bold type. Respect reduced-motion preferences and offer static background behavior.

## No additional stock photography needed
Use real website captures as the work imagery. Optional personal art can be added later, but is not needed for the first build. Text, panels, buttons, navigation and wordmark can be implemented as live text and CSS rather than flattened images.
