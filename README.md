# A. Halliwell Studio LLC Portfolio
Initial custom-coded portfolio build.

## Deploy
Upload all files to the repository root. The existing image assets should sit beside index.html:
- flower-backdrop.png
- flower-icon.png
- jelly-heart.png
- sparkle.png

Deploy as a static site on Vercel. No build command is required.

## Important
The ZIP includes the full website code. The four original PNG assets are not duplicated in this package because they already live in your GitHub repository. Keep those files when replacing/uploading the code.
