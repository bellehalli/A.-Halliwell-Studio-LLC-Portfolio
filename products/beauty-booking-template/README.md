# Beauty, Booked. — AHS Website Template

A responsive HTML, CSS, and JavaScript website starter for an independent beauty professional. Built for a hair stylist, nail artist, lash artist, esthetician, or small beauty studio.

## Pages included

- `index.html` — studio introduction, featured services, imagery, and booking calls to action
- `services.html` — service menu and starting prices
- `about.html` — studio story and approach
- `gallery.html` — portfolio gallery
- `policies.html` — appointment policies and preparation notes
- `book.html` — booking link, contact details, hours, and location

## Make it yours

1. Open `site-data.js` in a text editor.
2. Replace the sample studio name, address, phone, social link, and booking URL.
3. Update service names, descriptions, and prices in `services.html`.
4. Replace `assets/studio-hero.webp` and the gallery placeholders with your own licensed photographs.
5. Open `index.html` in a browser to preview the site.
6. Upload the whole folder to a web host connected to your domain. Domain registration, hosting, and appointment-booking software are purchased separately.

The template includes working navigation, responsive styling, and booking buttons that point to your existing scheduling page. It does not create appointment availability, take deposits, or process payments itself.
